# jmkerestes.com

Landing site for Jon-Michael Kerestes — Physical Integration Coaching.

Built with [Next.js](https://nextjs.org) and deployed on [Vercel](https://vercel.com) (auto-deploys on push to `main`).

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
```

The application form posts to [Formspree](https://formspree.io).
